# Proposed Dreamina-derived direction

Approved 2026-10-16: complete Re product interface. Marketing remains separate.

## Visual system
Charcoal canvas, slightly lighter central composer, thin neutral borders, cyan primary actions, white text with muted gray labels. Large centered editorial heading with a restrained italic phrase, compact primary navigation, wide rounded composer, compact settings chips and large visual starter cards. Use Re's own name and language.

## Screen composition
Create: primary sidebar; centered heading; Novel / Video / Context modes; large prompt field; optional title and input actions; inline supported settings; explicit open-workspace action. Below: original concept starter cards and recent real projects.
Explore: category chips and original visual prompts for cinematic, fantasy, mystery and alternate-ending work. Every card explains it is a prompt starter, not a clip. Selection fills reviewed input.
Projects: searchable real workspace cards with manuscript/video counts and last update. Existing projects open directly into their retained data, never reconstructed from mock content.
Workspace: compact project breadcrumb, Novel / Video modes and secondary Director / Timeline / World tools. Manuscript remains a readable central column. Story direction becomes a contextual inspector. Video input/results use the same palette and controls as Create.
Results: actual selected clip/job, status, failure or uncertainty message, prompt reuse, and preview/download only when a signed ready job exists. Job history remains selectable.
Mobile: compact top/scrollable navigation, single-column composer, touch-size controls and stacked cards; no horizontal page overflow. Keyboard focus remains explicit and motion respects reduced-motion.

## Preserve
Exact imported text, all existing workspaces, backups, revisions, branch isolation, canon approval, local autosave/recovery, server-only keys and per-request video consent.
