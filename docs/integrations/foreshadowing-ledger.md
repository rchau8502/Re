Upstream reports MIT licensing; this milestone uses an independently implemented native model, with no source code, dependency, database schema, prompts, agent host or third-party assets copied. Branch references are research pointers, not a pinned vendored revision. Upstream was not executed.

Scope: optional bounded author ledger inside the existing NovelState. A record has title, author notes, planted passage, optional planned chapter, and optional payoff passage. Author-selected evidence stores chapter ID, original UTF-16 start/end, chapter body revision and exact quote (up to 1,000 units). Reuse literal search to select an occurrence; at most 50 choices are shown. Any edit to a source chapter’s prose requires relinking its evidence, even when the same quote still appears at the same offset; this conservative rule prevents repeated-text collisions. Title/card/order changes do not change the separate body revision. Exact saved spans must still match before jumping or assigning payoff evidence. Changed/moved spans are not automatically reassigned to another matching occurrence: explicitly select and relink them.

Open/resolved/needs-evidence-review state is derived from actual evidence, never fabricated semantic certainty. A payoff must follow the planting in manuscript order (including same-chapter offsets). Reordering can invalidate payoff order or move the target before planting; display warnings rather than silently rewriting the record. Due reminders compare the active chapter with the optional target, not a calendar date.

Existing chapters, completion receipts, continuity approvals, storage, backup and branch-copy mechanisms remain authoritative. Ledger edits do not approve canon or alter manuscript text. Author notes and planned payoffs are excluded from AI context and manuscript exports in this version. No automatic extraction, plot-quality guarantee, external installation or model request. No deletion UI. Full-book JSON/world backups and branch copies retain entries; chapter snapshots restore prose/cards while leaving the ledger intact so evidence validity can be recomputed.

Bounds: 100 entries; title 200, notes 3,000, quote 1,000 UTF-16 units; existing 300,000 notebook / 400,000 full-draft limits still apply. Old notebooks without entries remain valid. Validation rejects malformed anchors and references to missing chapters, but preserves stale quoted spans for manual recovery.

Acceptance: domain regressions for exact evidence, repeated Chinese/emoji offsets, status/order/target changes, stale links, branch isolation, notebook limits, old archives, backup roundtrips and export/AI exclusion. Type checking/build and existing novel/continuity/history/writing regressions. Browser use with actual pasted Chinese prose, evidence selection, payoff assignment, jump/selection, shifted-source warning and reload preservation.
